# 青野壁纸开发进度

目标：Windows 10/11 桌面壁纸软件，奶白与鼠尾草绿风格，本地图库优先。

## 0.1.0 桌面预览版

- 四个自定义页面：今日精选、壁纸库、我的收藏、偏好设置。
- 随包附带十张有来源与许可信息的风景图片，断网可浏览。
- 导入 JPG / PNG / WebP / AVIF，SHA-256 去重；IndexedDB 保存图片文件。
- 收藏、搜索、分类、排序、图片预览、导出、偏好保存。
- 按本地日期生成稳定的每日精选，应用运行期间可按间隔轮换。
- Tauri 独立窗口，使用 Windows IDesktopWallpaper 接口设置桌面。
- 工具链、构建依赖位于 .tools；桌面版用户数据位于可执行文件旁的 data。
- Windows x64 便携 EXE 与 NSIS 安装程序。

## 0.1.1

- 每日联网下载默认 24 张；启动时补做，运行期间跨日检查，支持暂停。
- 下载落盘、许可记录、内容去重、每日计数持久化、来源限流等待、失败补齐与搜索游标。
- 图库总数、筛选计数、每页 12 张分页；随包示例扩充至 24 张。
- 新增来源调查，当前下载源仍为 Wikimedia Commons。

## 下一阶段

- 验证更多授权来源和国内网络可用性，增加原图质量选择、字节级断点续传。
- SQLite 元数据与原图/缩略图分层；导入目录与清理/备份流程。
- 托盘、关闭窗口后继续运行、用户可选开机启动、休眠后补做更新。
- 多屏独立壁纸、屏幕比例匹配、轮换历史持久化。
- 大图库虚拟滚动、缩略图与磁盘配额管理。
- 安装升级与迁移测试、签名与发布流程。

0.1.0 只有本地示例推荐；0.1.1 已接入真实每日联网下载。
