# 潮汐壁纸开发进度

## 1.1.0 当前功能

- Windows 原生桌面窗口，离线示例图库、搜索分类、收藏、导入、导出和桌面壁纸设置。
- 运行期间定时轮换、偏好保存、日期精选、每页 12 张。
- Wikimedia Commons、Openverse、NASA 多源下载，默认只选 Wikimedia，多来源按总量均分。
- 每日自动下载默认 24 张，可选 12/24/48；手动追加独立计数，下载期间按钮置灰、来源锁定。
- 下载类型在偏好设置中多选并保存，包含人物写真、山野、森林、海岸、湖泊、花卉和宇宙；NASA 仅在选中宇宙时参与。
- 图库与收藏页管理，跨页多选、选择当前页/全部筛选结果、批量删除和确认；示例隐藏及恢复，收藏同步清理，保留每日计数。
- 按标识和内容去重，来源独立冷却，保留作者、来源和许可信息。
- 在线关键词搜索，仅访问已选来源，每页最多 12 张，支持翻页、预览和下载入库。

## 后续计划

- 托盘驻留、开机启动、多显示器独立设置。
- 整合文件和数据库存储，增强数据迁移能力。
- 安装升级、长期运行、多设备兼容性和真实图片质量验收。
