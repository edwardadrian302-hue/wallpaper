# 潮汐壁纸 1.1.0 验证记录

日期：2026-11-16；Windows x64。

## 范围

- 图库管理、跨页多选、批量删除、收藏清理、示例隐藏与恢复。
- 原生删除只接受图库 ID，检查索引路径，暂存文件后保存索引；失败恢复，重复 ID 去重，下载期间拒绝删除。
- 保留删除后的每日完成计数，防止自动重新补齐；导入副本通过 IndexedDB 事务删除。
- 下载类型持久化与旧设置默认值，NASA 与类型兼容性过滤、有效来源配额、所选题材查询。
- 沿用多来源下载、在线搜索每页最多 12 张、名称与存储迁移。

## 检查

- 15 项前端测试和 17 项 Rust 测试通过；覆盖删除事务提交/中止、无效路径回滚、重复删除、下载锁定、每日计数保留及类型来源兼容。
- TypeScript/Vite 生产构建通过。
- Windows 原生 EXE、NSIS 安装包和便携 ZIP 构建通过，位于 release/1.1.0/。
- SHA-256、ZIP CRC、归档清单、归档内 EXE 与发行 EXE/原生构建一致性、安装包 PE 文件头校验通过。
- 24 张本地示例与署名记录、Git 差异格式检查通过。

## 边界

- 未进行原生窗口逐项交互、真实在线接口端到端下载或安装升级验收。
- 类型按搜索关键词划分，结果可能有偏差；来源收录、许可、横屏尺寸及限流仍生效。
- 安装包未签名；发布包的构建与完整性验证不替代安装升级验收。
