# 0.1.2 桌面专用清理

日期：2026-11-06。

已清理：

- 独立网页预览命令和未使用的浏览器 E2E 测试入口。
- Playwright 及其两项附带依赖，同步更新 package-lock.json 和许可清单。
- 浏览器版的导出下载链接、打开来源备用逻辑、模拟轮换分支及浏览器专用文案。
- 不再提供可在浏览器中操作的壁纸产品界面；界面入口检查 Tauri 桌面环境。

保留：

- Tauri 内部必需的 HTML、React、Vite、WebView2 和本机开发通信地址。
- 桌面图片详情与桌面效果预览，设置壁纸和导出均调用原生接口。
- 每日下载、图片来源和许可记录、收藏、分页及已有数据。
- 旧版桌面发行文件与历史验证记录。

开发入口 `npm run dev` 现在启动桌面窗口；`dev:ui` 仅由 Tauri 内部调用。

验证：前端 8 项检查和 TypeScript/Vite 生产构建通过。源码与新构建资源中不再包含浏览器版备用界面和 Playwright 入口。每日下载与分页的验证见 [0.1.1 记录](VALIDATION-0.1.1.md)。

0.1.2 独立 EXE 与中文安装程序已生成，便携包完整性与发行文件 SHA-256 通过。隔离桌面窗口实际启动成功，显示 v0.1.2、今日下载 24/24、图库共 48 张；Tauri 环境检查未阻止正常桌面启动。旧版文件、原有 data 目录和来源许可记录均保留。
