青野壁纸 v0.1.2 是面向 Windows 10/11 x64 的桌面开发预览版，使用时无需 Node.js 或本地开发服务器。

## 下载与使用

- `Qingye-0.1.2-x64-Setup.exe`：中文安装程序，可选择安装目录。
- `Qingye-0.1.2-x64-Portable.zip`：完整便携版，解压后运行 `Qingye.exe`，保留同目录的 `WebView2Loader.dll`。
- 需要 Microsoft Edge WebView2 运行环境；安装程序可在缺少运行环境时获取它。
- 收藏、设置、导入和下载数据保存在程序旁的 `data` 目录。移动便携版时请一并保留。
- 文件校验见 `SHA256SUMS.txt`，图片与开源组件许可见随附说明文件。

## 功能

- 每日联网下载默认 24 张，当前来源为 Wikimedia Commons。保留作者、来源、许可和内容哈希，成功下载后自动加入本地图库。
- 重启只补齐当天不足的数量，支持暂停、失败重试和来源限流等待。
- 随包提供 24 张离线示例；支持本地导入、内容去重、收藏、搜索、分类、排序、图片导出及 Windows 桌面壁纸设置。
- 壁纸库显示总数与筛选结果，每页 12 张。
- 奶白与鼠尾草绿的自定义界面，提供图片详情和桌面效果预览。
- 清理了早期网页原型入口、浏览器版备用逻辑和未使用的浏览器测试依赖，开发入口统一为桌面窗口。
