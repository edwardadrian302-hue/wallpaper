# 潮汐壁纸 1.0.0

- 产品名称、内部包名和应用标识统一为潮汐 / Chaoxi。
- 支持 Wikimedia Commons、Openverse、NASA 多源，默认 Wikimedia，按来源平均分配下载数量。
- 每日自动下载默认 24 张；手动追加不占每日额度，任务期间按钮置灰。
- 自动题材为人物写真、自然风景和宇宙。
- 新增在线搜索：任意关键词，仅搜索已选来源，每页最多 12 张，支持翻页、预览、来源/许可查看及下载到图库。
- 保留图库、收藏、导入、导出、桌面设置和定时轮换。
- 统一存储命名，迁移可读取的既有收藏、偏好和导入图片，原始数据保留。
- 清除项目内旧版发行产物、历史版本文档和旧构建缓存，仅保留当前发行版本。

安装程序：release/1.0.0/Chaoxi-1.0.0-x64-Setup.exe。

完整便携包：release/1.0.0/Chaoxi-1.0.0-x64-Portable.zip。

使用新目录安装，复制 EXE 旁完整 data 目录以保留数据。跨应用标识安装升级、导入迁移和完整界面交互尚未验收。此版本未签名，未上传 GitHub Releases。

界面修正：将「偏好设置」放入主导航，移除底部装饰对入口的影响；侧栏支持独立滚动，窗口高度不超过 800 CSS 像素时隐藏装饰并收紧间距。
