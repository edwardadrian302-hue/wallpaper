# 潮汐壁纸 1.1.0

- 图库与收藏页增加管理模式、跨页多选、当前页选择、全部筛选结果选择及批量删除确认。
- 下载与导入副本实际删除，关联收藏同步清理；导入原文件、已导出文件及当前桌面副本保留。
- 随包示例仅隐藏，可在偏好设置恢复；删除保留每日下载计数，下载或导入期间锁定删除。
- 偏好设置新增七种下载类型，多选自动保存，每日及手动追加任务使用当前选择。
- NASA 仅在选中宇宙时参与，其他所选来源平均分配数量；关键词在线搜索保持独立。
- 延续 1.0.0 的固定可见设置入口。

## 本次发布包含的升级

相对于 GitHub 上的 0.1.2，本次统一更名为潮汐 / Chaoxi，并包含 Wikimedia Commons、Openverse、NASA 多来源选择与均分下载、独立于每日额度的手动追加下载，以及按当前有效来源搜索的在线图库（每页最多 12 张）。默认采用 Wikimedia，设置自动保存。内置跑车和游戏分类已移除。

## 下载与升级

- Windows 10/11 x64：安装版使用 Chaoxi-1.1.0-x64-Setup.exe。
- 便携版使用 Chaoxi-1.1.0-x64-Portable.zip，完整解压后运行 Chaoxi.exe。
- 请先退出程序，保留原程序旁的 data 目录；升级前建议备份该目录。旧青野版本到潮汐的完整安装迁移尚未验收，请保留旧数据。
- SHA256SUMS.txt 提供安装包、便携包、独立 EXE 和运行库的校验值。
- 依赖 Microsoft Edge WebView2，安装包未签名。
